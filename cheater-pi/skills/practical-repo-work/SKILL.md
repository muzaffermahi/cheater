# Cheater Practical Repo Work

Use this skill when doing ordinary repository work in Cheater.

1. Start with the smallest relevant search or file read.
2. Prefer Pi's native tools for search, reading, editing, shell execution, context handling, and sessions.
3. Keep diffs small and local to the requested behavior.
4. Run the narrowest useful test first.
5. Treat tests, dependency files, lockfiles, and large edits as higher-risk changes that deserve explicit attention.
6. Summarize the final change and verification briefly.
